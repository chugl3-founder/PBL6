# KHO DỮ LIỆU TRI THỨC CẦU LÔNG (KNOWLEDGE BASE)

Thư mục này dùng để lưu trữ các tài liệu chuyên môn cầu lông phục vụ RAG.
Bạn chỉ cần tải hoặc thả tài liệu vào các thư mục tương ứng:

## 📁 Cấu trúc thư mục:
- `01_rules/`: Luật thi đấu cầu lông chính thức (BWF Laws of Badminton), quy định kích thước sân, luật giao cầu, tính điểm, thẻ phạt,...
- `02_tactics/`: Giáo trình chiến thuật đánh đơn, chiến thuật đánh đôi, cách khai thác điểm yếu đối thủ, chiến thuật điều cầu 4 góc, chuyển từ phòng thủ sang phản công,...
- `03_techniques/`: Kỹ thuật chi tiết các cú đánh (Smash, Clear/Lốp cầu, Drop/Chặt cầu, Drive, Net play/Kéo lưới, Lift/Hất cầu), kỹ thuật cầm vợt (Grip) và bộ chân di chuyển (Footwork).
- `04_fitness_injury/`: Giáo án rèn luyện thể lực, bài tập bổ trợ cổ tay, sức bền, cách khởi động, phòng ngừa và xử lý chấn thương khớp gối, cổ chân, vai.

## 📄 Các định dạng file đọc tốt nhất:
1. `.md` (Markdown) - TỐT NHẤT: Tiêu đề rõ ràng, bảng biểu chuẩn xác.
2. `.pdf` (Digital PDF): File PDF chứa chữ có thể bôi đen copy được (không phải file scan chụp ảnh).
3. `.txt`: File văn bản thuần túy.
4. `.docx`: File tài liệu Word.
